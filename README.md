# Starlinks API documentation

The API reference for Starlinks distributors, published with GitHub Pages at
https://docs.starmakersdistro.com and shared privately (not listed in search engines).

- `openapi.json` — the API (OpenAPI 3.1), generated in the website repository by
  `node scripts/generate-openapi.mjs` (writes `docs/starlinks-openapi.json`). Copy it here to update the docs.
- `index.html` — renders it with [Scalar](https://github.com/scalar/scalar).
- `CNAME` — the custom domain.
