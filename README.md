# Amplika for distributors

Amplika by Star Makers Distribution (formerly Starlinks): music links infrastructure.

Smart links, pre-saves, analytics and promo images for your artists and labels, under your own brand.

**Full documentation: https://docs.starmakersdistro.com**

## Two ways to integrate (use either, or both)

| Compare | Option 1: Embed (iframe) | Option 2: API |
|---|---|---|
| What it is | Our link creator inside a page of your platform | Your server creates and manages links |
| Developer work | Paste one snippet, no backend needed | Calls to the REST API, optionally webhooks |
| Who creates links | Your users, themselves | Your platform, automatically (e.g. on delivery) |
| Best for | Launching in minutes | Full automation and catalogue sync |

Both use your branding and show up in your distributor portal, where you also get your embed code and API key.

### Option 1: Embed (iframe)

Copy your code from the portal (it contains your embed key) and list the domains where you'll use it. It looks like this:

```html
<iframe id="starlinks-embed" src="https://www.starmakersdistro.com/embed/<your embed key>" title="Create a smartlink" width="100%" height="900" style="border:0;border-radius:16px;max-width:1100px" loading="lazy" allow="clipboard-write; web-share"></iframe>
<script>
  window.addEventListener("message", function (event) {
    if (event.origin !== "https://www.starmakersdistro.com" || !event.data || event.data.type !== "starlinks:resize") return;
    document.getElementById("starlinks-embed").style.height = event.data.height + "px";
  });
</script>
```

Optional account linking (your signed-in users see **My links**), with Node.js, PHP and Python examples: see *Option 1: Embed* in the documentation.

### Option 2: API

```bash
curl -X POST "https://amp.starmakersdistro.com/api/v1/links" \
  -H "Authorization: Bearer $AMPLIKA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "upc": "196871234567", "release_date": "2026-11-20T00:00:00Z", "owner_email": "artist@example.com" }'
```

Every endpoint, field and webhook is in the documentation and in [`openapi.json`](openapi.json) (OpenAPI 3.1: import it into Postman, Apidog or Insomnia, or generate a client).

## Files

- `index.html` renders the documentation with [Scalar](https://github.com/scalar/scalar).
- `openapi.json` is the API description, generated by Star Makers Distribution.
- `CNAME` sets the custom domain.
